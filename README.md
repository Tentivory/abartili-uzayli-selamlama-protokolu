# 🌌 ABARTILI UZAYLI SELAMLAMA PROTOKOLÜ v3.14

## Resmi Galaksiler Arası Diplomasi Yazılımı

Bu depo, **Evrenler Arası Barış ve Selamlama Birliği** tarafından onaylanmış, en üst düzey abartılı uzaylı selamlama protokolünü içerir.  
Bu yazılım olmadan galaksiler arası diplomasi **imkansızdır**.  
Uymayan medeniyetler, "Selamlaşmayanlar Listesi"ne alınır ve sonsuza dek yalnız bırakılır.

### 🚀 Kurulum ve Çalıştırma

